🎧 Nevis - Votre Univers Musical Intelligent

https://musicneviss.netlify.app/home

Nevis est une plateforme musicale moderne que j'ai conçue et développée dans le cadre de mon apprentissage frontend. Cette application web combine découverte musicale, actualités, gestion de concerts et personnalisation du profil utilisateur.


🎯 Objectifs d'Apprentissage
✅ Design System complet : Création d'une identité visuelle cohérente

✅ Responsive Design : Adaptation mobile/tablette/desktop

✅ Navigation fluide : Système de routing intuitif

✅ UI/UX avancé : Micro-interactions et états visuels

✅ Gestion d'état : Données utilisateur persistantes
